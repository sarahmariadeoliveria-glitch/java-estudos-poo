java-estudos-poo

 Sobre o projeto

Criei este repositório para reunir os exercícios que venho desenvolvendo durante meus estudos de Programação Orientada a Objetos (POO) com Java. Em vez de deixar os códigos separados, resolvi organizá-los aqui para acompanhar minha evolução e ter um lugar onde posso revisar o que aprendi e comparar meu progresso ao longo do tempo.

Cada exercício tem um objetivo diferente. Alguns são mais simples e servem para praticar a sintaxe da linguagem, enquanto outros exigem um pouco mais de raciocínio para aplicar os conceitos da orientação a objetos de forma correta.

 O que estou praticando

Ao longo dos estudos, estou aprendendo a criar programas mais organizados e reutilizáveis, utilizando os principais conceitos da Programação Orientada a Objetos. Entre eles estão:

* criação de classes e objetos;
* atributos e métodos;
* construtores;
* encapsulamento;
* herança;
* polimorfismo;
* abstração;
* organização do código e boas práticas.

Além disso, cada exercício também contribui para desenvolver minha lógica de programação e me ajuda a entender melhor como esses conceitos são utilizados no desenvolvimento de aplicações em Java.

 Objetivo

O principal objetivo deste repositório é registrar meu aprendizado e acompanhar minha evolução na linguagem Java. Conforme avanço nos estudos, pretendo adicionar novos exercícios e desafios, aplicando conteúdos cada vez mais complexos e melhorando a forma como escrevo e organizo meu código.

Este repositório também faz parte do meu portfólio, mostrando um pouco da minha trajetória de aprendizado e do conhecimento que estou construindo durante a graduação e os estudos por conta própria.
